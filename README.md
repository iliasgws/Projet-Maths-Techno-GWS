# Projet Maths-Techno
Pour notre projet, on a voulu régler un problème tout simple mais récurrent à l'école : quand on tape directement des notes dans Excel, on fait vite des erreurs de frappe ou de formules. 
On veut donc créer un petit programme en Python avec Tkinter pour avoir une fenêtre facile à utiliser pour tout le monde.
 Concrètement, l'élève ou le prof remplit le formulaire, le programme vérifie qu'on n'a pas mis de texte dans une case de note, calcule la moyenne tout seul, puis met à jour le fichier Excel et l interface à l'écran. 
Le plus difficile pour nous sera de gérer les erreurs de saisie et de synchroniser le tableau sans faire planter le script.
