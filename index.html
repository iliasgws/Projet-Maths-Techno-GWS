Projet Maths-Techno

Application de bureau pour saisir les notes des eleves, calculer leur moyenne et les enregistrer dans un fichier Excel. Hors ligne, simple a utiliser.

Demarrage rapide

  1. Telechargez l'archive pour votre systeme dans les releases.
  2. Extrayez l'archive, puis lancez Projet-Maths-Techno en double-cliquant dessus.
  3. Remplissez le formulaire et cliquez sur Ajouter : c'est tout.

A quoi sert l'application

L'application verifie les donnees avant de les ecrire dans Excel, calcule la moyenne automatiquement et garde le fichier data/notes.xlsx comme seule source de verite.

Installer l'application

Version prete a l'emploi (Windows, macOS, Linux) disponible sur GitHub Releases. Sur macOS : clic droit puis Ouvrir au premier lancement.

Ou depuis les sources : Python 3.10+ puis

git clone https://github.com/iliasgws/Projet-Maths-Techno-GWS.git
cd Projet-Maths-Techno-GWS
python -m pip install -r requirements.txt
python main.py

Premiers pas

  • Nom, classe et lettre a choisir dans les listes.
  • Trois notes sur 20, virgule ou point acceptes (12,5).
  • Cliquez sur Ajouter pour enregistrer, Vider pour recommencer.

Utiliser l'application

BoutonAction
AjouterEnregistre l'eleve saisi
ModifierModifie l'eleve selectionne dans le tableau
SupprimerSupprime l'eleve selectionne (confirmation)
ViderVide le formulaire et deselectionne

Cliquez sur une ligne du tableau pour la recopier dans le formulaire et la corriger.

Regles de saisie

  • Nom non vide.
  • Classe et lettre choisies dans les listes.
  • Notes entre 0 et 20 (virgule ou point acceptes).
  • Unicite Nom + Classe (classe et lettre assemblees).

Ou sont mes notes

Les notes sont dans data/notes.xlsx, feuille Notes. Colonnes : ID, Nom, Classe (ex. 2BAC-B), Mathematiques, Sciences, Histoire, Moyenne (arrondie a deux decimales). Moyenne = (M + S + H)/3.

En cas de probleme

  • Fichier ouvert dans Excel : fermez-le puis reessayez.
  • macOS (application non signee) : clic droit puis Ouvrir.
  • Linux/Tkinter : sudo apt install python3-tk.

Pour les contributeurs

Le depot comprend main.py, des tests dans tests/, requirements.txt (openpyxl uniquement), un CHANGELOG et un guide de contribution. Test : python tests/test_gui.py.
